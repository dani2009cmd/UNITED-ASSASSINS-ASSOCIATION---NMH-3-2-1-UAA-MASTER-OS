Setup Protocol
1. Run as Administrator: Right-click the included nmh_accessibility.exe (or the .au3 script) and select Run as Administrator—otherwise Windows blocks macro inputs from hitting the game process.
2. Match Your Layout: Tap F4 in-game to open the GUI, line up the Target Game Keys with your controls, and hit SAVE & APPLY.
3. Go to Work: Fire up the game and go turn the next rank-holder into red mist.
